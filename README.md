I design, build, and run enterprise end-user computing platforms on Azure and AWS. For more than 12 years I have delivered virtual desktop and application estates for large, regulated, multi-brand organisations: Citrix, Azure Virtual Desktop, Windows 365, FSLogix, and NetScaler, integrated with Entra ID and Intune and automated with Terraform and PowerShell.

My current work combines that EUC and cloud background with AI: operational agents, MCP servers, and RAG pipelines that help IT teams troubleshoot and run desktop estates faster.

## What I work on

| Area | Details |
|---|---|
| **Cloud architecture** | Azure landing zones (CAF), hub-spoke networking, identity, governance and policy, hybrid Azure/AWS connectivity |
| **Azure Virtual Desktop** | Host pool design, FSLogix profile architecture, scaling plans and cost optimisation, image management, Nerdio Manager for Enterprise |
| **Windows 365** | Enterprise and Frontline Cloud PCs, Azure Network Connections, Intune provisioning, security baselines, lifecycle management |
| **Citrix** | Citrix DaaS and Virtual Apps and Desktops, MCS, Autoscale, Cloud Connectors, NetScaler ADC / Gateway, hybrid multi-site estates |
| **Automation** | Terraform, Bicep, PowerShell (including the Citrix DaaS Remote PowerShell SDK), Azure CLI, GitHub Actions |
| **AI for IT operations** | MCP servers, RAG pipelines (Python, Qdrant), n8n workflows, AI helpdesk and diagnostic agents |
